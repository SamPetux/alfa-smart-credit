# Описание решения

«Умный кредитный кабинет» — веб-прототип для малого и микробизнеса, который проводит предпринимателя от выбора цели финансирования до предложения условий, оформления документов и смоделированной выдачи: клиент заполняет короткую заявку, видит сохранённые данные, ход рассмотрения и конкретные следующие действия, а система проверяет сведения через локальные симуляторы источников, рассчитывает объяснимую оценку риска и передаёт сотруднику банка готовое досье с рекомендацией. Основная особенность решения — подбор посильных условий на основе финансовых показателей: если запрошенная сумма не проходит правила демонстрационной кредитной политики, система проверяет допустимую альтернативу и объясняет её отличие; недостающие сведения запрашиваются внутри кабинета, а технический сбой никогда не превращается в кредитный отказ. В базовой версии итоговое предложение или отказ подтверждает сотрудник банка, клиент самостоятельно принимает либо отклоняет предложение, а история проверок, версий данных и решений сохраняется для воспроизведения; весь сценарий работает в Docker на синтетических данных без платных API и доступа к системам банка.

Текст описывает целевую реализацию, а не уже созданный продукт. Название рабочее. Срок обработки, экономический эффект и качество модели не заявляются как доказанные до измерений. Предложенная кредитная политика учебная и не воспроизводит правила Альфа-Банка.
