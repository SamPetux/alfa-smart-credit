# Пакет проектирования кредитного кабинета

Подготовлен по исходному кейсу и расшифровке созвона 24 октября 2026 года. Это инструкции к разработке, а не реализованный банковский сервис. Формат Markdown выбран для прямого использования в GitHub и передачи ИИ-агентам.

Рекомендуемое размещение в новом репозитории — `docs/planning/`, а согласованные общие правила — в корневом AGENTS.md. Ссылки на `01-team-instructions.md` и `02-architecture.md` в инструкциях при переносе скорректировать. Не заменять корневой README продукта этим README пакета: продукту нужна инструкция фактического запуска.

Старт команды: подтвердить владельцев и доступность Рамазана; принять P0 и контракты; создать каркас; собрать один полный сценарий; расширять только после совместной проверки. Не требуется создавать пять отдельных репозиториев или пять отдельных серверов.

Диаграммы Mermaid находятся в архитектуре и отображаются в GitHub. Архитектурные номера версий относятся к нашим контрактам, а не к выпускам сторонних библиотек. Точные зависимости фиксирует команда после проверенной сборки.

Численные policy-параметры вымышлены для демонстрации. Исследования и экономический эффект не проводились в рамках подготовки этого пакета. Успех в соревновании зависит от реализации и оценки жюри.
