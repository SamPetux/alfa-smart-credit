## Решения прототипа и их границы

| Решение / допущение | Основание | Ограничение |
|---|---|---|
| Две роли, одна компания на клиента | P0 | Многокомпанейность / production IAM вне P0 |
| Открытый выбор демопрофиля | Архитектура §11 | Демо-вход ≠ доказательство личности |
| Локальные симуляторы БКИ и реестра | R09/R12/R14 | Реальные источники не проверяются |
| Учебные score и policy-v1 | R17 | Нет калибровки на портфеле банка |
| Окончательное предложение/отказ — OFFICER | P0 | Ручной шаг не гарантия правильности |
| Аннуитет, без залога/поручительства | Архитектура §7 | Не действующий банковский продукт |
| Демо-документы | Архитектура §7, §11 | OCR/антивирус/подлинность вне P0 |
| Предложение без автоистечения | Архитектура §4 | Упрощение P0 |
| Подпись и выдача имитируются | R14 | Нет ЮЭП и перевода средств |
| Без обязательных платных API / LLM | R12/R16 | Первая загрузка образов может требовать сеть |
| Автоэтап до ~120 с | Архитектура §13 | Не SLA |
