# Frontend: клиентский и банковский кабинеты

Владелец: Игорь (F01–F10). React 19 + TypeScript + Vite, React Router, TanStack Query. UI-библиотеки нет,
шрифт Golos Text подключён локально (`@fontsource-variable`, OFL), CDN не используется.

## Запуск

```bash
cd frontend
npm ci
npm run dev            # http://127.0.0.1:5173, /api проксируется на 127.0.0.1:8000
```

Backend нужен настоящий (API + worker + PostgreSQL, см. корневой README). Другой адрес API:
`VITE_API_PROXY=http://host:port npm run dev`. Frontend-моков с готовыми результатами нет.

| Команда | Что делает |
|---|---|
| `npm run typecheck` | `tsc --noEmit` |
| `npm test` | unit и component-тесты (Vitest + Testing Library) |
| `npm run build` | typecheck и production-сборка в `dist/` |
| `npm run gen:api` | генерирует `src/api/schema.gen.ts` из `contracts/openapi.json` |
| `npm run check:api` | проверяет, что сгенерированные типы не отстали от контракта |

## Маршруты

| Путь | Роль | Задача |
|---|---|---|
| `/demo` | все | F01: выбор демопрофиля; при `DEMO_MODE=false` — вход тестовым аккаунтом |
| `/applications` | CLIENT | F01: главная, заявки компании и следующий шаг |
| `/applications/new` | CLIENT | F02: выбор продукта и создание черновика |
| `/applications/:id/edit` | CLIENT | F02: черновик, явное сохранение, документы, отправка |
| `/applications/:id` | CLIENT | F03/F04: статус, история, уточнение, предложение, документ, имитация подписи |
| `/bank/applications` | OFFICER | F05: очередь с серверными фильтрами |
| `/bank/applications/:id` | OFFICER | F06/F07: досье и решения |

Проверка роли в маршрутах нужна только для навигации. Доступ к каждому объекту проверяет сервер.

## Устройство

- `src/api/` — F09. `http.ts`: cookie-сессия, `X-CSRF-Token` на изменения, `Idempotency-Key`,
  нормализация ошибок (envelope из `contracts/` и стандартный ответ FastAPI). `session.tsx`: смена профиля
  отменяет запросы прежней сессии, отбрасывает опоздавшие ответы, очищает кэш и пересоздаёт дерево UI.
  `useCommand.ts`: ключ идемпотентности повторяется только после сетевой ошибки или 503; после 409
  автоматического повтора нет.
- `src/components/` — F08: поля с подписями и ошибками рядом, денежный ввод (наружу строка или `null`),
  статус, timeline, диалог подтверждения на `<dialog>`, документ, состояния loading/empty/error.
- `src/shared/` — статусы и подписи из `contracts/statuses.json`; форматирование Money строками без float.
- `src/features/client`, `src/features/bank` — экраны.

Источники правил: статусы — `contracts/statuses.json`; коды причин отказа — `contracts/schemas/risk-v1.output.json`;
шаг суммы и обязательные документы — `contracts/schemas/policy-v1.json`; границы суммы и сроки — `GET /products`.
Frontend не вычисляет score, ставку, платёж, DSCR и разрешения: показывает значения сервера.

## Ограничения и заглушки

- **`company_form`.** В контракте это свободная строка. UI предлагает `LLC` (из примера контракта) и `IP`. Нужен enum в контракте.
- **Ответы без схемы.** Досье (`risk_summary`, `checks`, `revisions`, `audit`), история, explain и upload
  в OpenAPI описаны как `dict`. Типы для них в `src/api/types.ts` написаны вручную.
- **Очередь.** Сортировки на сервере нет (порядок задаёт backend), пагинации курсором нет: показываются первые 50.
- **Время событий.** События одной транзакции имеют одинаковое время, и их порядок в истории может не совпадать с логическим.
- **Тестовые заявки.** Отдельного раздела нет: у заявки нет признака «тестовая».
- **Тексты причин.** Пояснения кодов причин для сотрудника взяты из таблицы `02-architecture.md` §7. Клиент видит шаблонные объяснения сервера (`/explain`).
- Автосохранение черновика (P1) не реализовано, сохранение явное.

## Закрыто на backend (main)

- Compose `infra/Dockerfile.web` собирает `frontend/dist` (Node ≥ 20.19) и отдаёт SPA через Caddy.
- CSRF: мутации требуют заголовок `X-CSRF-Token` (без подстановки из cookie).
- Offer `terms` включает `monthly_payment` и `total_payment`; `GET /applications/{id}/documents` — список файлов.
- NEEDS_INFO PATCH ограничен полями открытого `info_request`; `demo_scenario` клиентом не задаётся.
